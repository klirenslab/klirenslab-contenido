# Klirenslab · contenido

Archivos públicos de las publicaciones de Klirenslab, enlazados desde Buffer para programarlas.

- `linkedin/<publicación>/documento.pdf`: carrusel que LinkedIn muestra como documento.
- `linkedin/<publicación>/miniatura.jpg`: portada del documento.
- `linkedin/<publicación>/texto.txt`: texto de la publicación.

Los archivos tienen que seguir acá hasta que la publicación salga.
